# Уран в Toxic Caves

Правило `alexscaves_toxic_caves_uranium.json` загружается. Селектор
`#c:ores/uranium` проходит существующую унификацию материала; `forced: true`
использует `count`, а `frequency` для этого режима не требуется.

При явном `replaceables: ["alexscaves:radrock"]` MEDIUM/LARGE раньше
проверяли radrock в удалённом базовом столбце генератора. Alex's Caves
преобразует исходный камень в radrock на стадии поверхностей, поэтому базовый
столбец ещё не содержит разрешённой породы. План получался пустым.

В `DataDrivenOreDepositBiomeModifier` добавлено получение разрешённых пород,
создаваемых тем же модом, которому принадлежит целевой биом. В
`OreDepositFeature.buildCompactPlanAt` исходный `#c:stones` допускается как
предшественник этой породы только при планировании. У forced-центров биом уже
проверен по реальной палитре генерируемого чанка; повторная удалённая проверка
биома не требуется. Для обычных правил сохраняется проверка планируемого биома.

Перед размещением по-прежнему проверяется фактический `replaceables`:
правило с radrock не получает разрешения заменять обычный камень, воздух
или жидкости. Добавлена диагностика отклонений плана по породе. Геометрия,
запасы, forced-учёт и формат данных не изменены.

Регрессионный GameTest запускается с реальными Alex's Caves 2.0.10 и Citadel
2.7.5 из `run/mods`: проверяется загрузка пользовательского JSON, затем
контролируемое правило radrock. Базовый шумовой камень берётся из Нижнего мира,
а позднее преобразование в radrock воспроизводится в изолированном тестовом
мире. Тест проверяет MEDIUM/LARGE, запрет размещения в непреобразованном камне,
размещение после преобразования по всем чанкам и точную сумму ресурсов.
Это проверка взаимодействия стадий; она не заменяет проверку естественной
Toxic Caves в пользовательской сборке.

Прошли 124 JUnit и все 16 GameTest с подключёнными Alex's Caves/Citadel.
Результат контролируемого правила: MEDIUM — 2 254 блока, 106 860 единиц
ресурса, 7 чанков; LARGE — 18 346 блоков, 2 737 229 единиц, 21 чанк.
В обычном камне обе залежи не размещались; после преобразования в radrock
весь запас размещён без потерь и дублирования.

Команда: `./gradlew.bat build runGameTestServer -PcompactGameTests -PalexCavesGameTests --console=plain`.
Без `alexCavesGameTests` дополнительные моды не подключаются; тест поздней
породы явно пропускается. Тестовый JSON находится только в `src/gameTest/resources`
и не включается в готовый мод. Лог: `build/uranium-rule-test.log`.

Изменённое правило действует в новых чанках после перезапуска клиента.
Уже сгенерированные участки автоматически не пересоздаются.
